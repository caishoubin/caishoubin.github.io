Privacy

Your factory inputs stay in your browser. This site has no account, input-upload endpoint or analytics script.

INDEPENDENT FAN TOOL · SOLID-ITEM LOGISTICS · UPDATED 21 OCT 2026

Calculator inputs

Numbers entered into both calculators are processed in JavaScript on your device, without an input-upload endpoint. By default, reloading restores the examples. If you enable “Remember on this device,” the last valid inputs for both calculators, selected tab and stack-size helper are saved in this browser’s local storage. Invalid edits do not replace the last valid plan. Uncheck the option or use “Reset plan” to remove that saved plan. Clearing this site’s browser data also removes it. Storage may be unavailable in private or restricted browsing. Other scripts served from the same site origin can access its local storage; this version contains no third-party scripts.

Shareable plan links

“Copy plan link” creates a snapshot of both calculators in the URL fragment, the part after #. The link does not include query parameters. Fragments are not sent as part of ordinary HTTP requests to the hosting server, but the complete link can be seen by anyone you share it with and may be stored in browser history or browser-sync services. This is not encrypted storage. Do not put private information in a plan link. Opening a valid shared plan takes precedence over locally remembered inputs without changing the saved plan until you edit or enable remembering.

Clipboard

The “Copy result” and “Copy plan link” buttons write a summary or link to your clipboard only after you press one. If access is blocked, the plan link remains available in a selectable field. It does not read your clipboard. Other applications with clipboard access may be able to read content you copy; the site cannot control those applications.

Hosting and ordinary web requests

This site is hosted on GitHub Pages. Visiting it necessarily sends ordinary connection information, such as an IP address and browser request information, to the hosting provider. GitHub may process that information under its own privacy statement. “Local calculations” does not mean that the hosting provider receives no request data.

Cookies, analytics and advertising

This version does not set application cookies, use analytics, load advertising scripts or request personalized advertisements. It includes a public Google AdSense account ownership metadata tag. That tag alone does not serve advertising and is not a claim of AdSense approval.

If advertising or analytics is introduced later, this notice should be updated to describe the providers, data flows and any applicable consent choices before those features are enabled.

External links

Links to the wiki, GitHub and sibling tools open other pages that may have their own data practices. No external fonts, game assets or remotely hosted libraries are needed to use this calculator.

Publisher

The publisher is caishoubin on GitHub. There is no newsletter, account registration or contact form on this site. This notice covers this version of Belt & Buffer only.
