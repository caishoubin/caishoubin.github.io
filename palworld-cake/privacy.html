Your pantry stays in your browser

Updated October 21, 2026 · Normal Cake reference snapshot

No account, inventory upload or background connection is needed. The calculator runs in your browser using the files served with this page.

What this tool does not collect

This implementation contains no analytics, advertising scripts, tracking pixels, cookies, external fonts or runtime requests for recipe data. It does not connect to your game, a Palworld account, or a private backend. Your typed quantities are not submitted by the calculator.

Ordinary page and asset requests still reach the static hosting provider, which can receive normal request metadata such as an IP address and browser information. Visiting a source or publisher link opens another website with its own policies.

Remembering is optional

The “Remember on this device” checkbox starts off unless this tool finds a valid saved plan. When enabled, complete valid inputs are stored in this browser’s local storage under a tool-specific key. This includes your target, ready count, ingredient counts and gathering route, but no identity or account data.

Invalid edits never replace the last valid saved plan. Turn remembering off to remove this tool’s saved plan. Outside shared-preview mode, “Reset & forget” also removes it and restores the sample values. Other tools’ saved plans are not deleted.

If the browser blocks storage or it is full, calculations still work and the page reports the problem. If deletion is blocked, an older saved plan may remain; clear this site’s browser storage to erase it. Private browsing and browser cleanup can remove saved plans. There is no server copy to recover.

Shared snapshots do not overwrite your plan

A valid plan link takes precedence over local inputs for that session. Loading or editing a shared snapshot does not write it into storage. Remembering is disabled while it is a temporary shared snapshot.

“Save this shared plan” explicitly replaces the tool’s saved plan on that device and enables future valid changes to be remembered. “Return to saved plan” restores the prior saved plan, or the example if none is available. “Reset shared preview” resets only the temporary inputs to the sample values and preserves your saved plan. An invalid link leaves your current and saved plan unchanged.

Share links are readable, not secret

Copied plan links put the snapshot after the # character, in the URL fragment, not in query parameters. Fragments are not sent in ordinary HTTP page requests. However, anyone with the complete link can read the counts, and browser history, sync, extensions or messaging services may retain the full link. Sharing is not encryption or access control.

Editing a loaded snapshot removes its now-stale plan fragment from the address bar, while keeping the snapshot temporary until you explicitly save it. Links already copied elsewhere do not update.

Copying and exporting

Copy buttons use the browser clipboard only after you click them. If clipboard access is unavailable, selectable text is provided. A text download is generated locally in your browser. You choose where exported text or links go next.

Advertising status

The pages include an AdSense account-ownership meta tag for the publisher. It is not an ad-serving script. No advertisements are loaded by this implementation, and the tag makes no claim about approval or revenue. Any future advertising or analytics requires a new privacy review.
