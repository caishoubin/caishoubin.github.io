Privacy

Your checklist stays close.

Plain-language information about local progress, hosting, external links, and what this version of the site does not collect.

3 min readUpdated October 20, 2026Independent guide

Progress is stored in your browser

The checklist uses your browser’s localStorage, when available, to remember which entries you mark complete. It stores a small list of known checkpoint identifiers with an application name and format version. The key is before-hardmode.progress.v1. It does not read Terraria files or connect to your game.

There is no site account, cloud sync service, or publisher-operated backend receiving checklist progress. Clearing site data or using the Reset checklist control removes the active progress. Local saving can be blocked or temporary in private browsing or under browser policies.

Browser storage belongs to an origin, which includes the website’s protocol, host, and port. Other pages on the same GitHub Pages origin can technically access it. The checklist data is not encrypted by this app. Avoid storing confidential information in a progress file.

Imports and exports stay on your device

Export creates a JSON file through your browser. Import reads the file you select and validates its contents locally; the site does not upload that file. You are asked to confirm before imported progress replaces the current checklist.

If you send an exported file to another person or a storage provider yourself, that sharing is controlled by the service you choose. A planner export contains checklist identifiers, not your Terraria world or character files.

GitHub Pages delivers the website

The site is designed to be served by GitHub Pages. When you visit a hosted page, the hosting provider necessarily receives normal connection information such as your IP address and browser request data. GitHub may process this information under its own policies. See the GitHub General Privacy Statement for details.

Pages, fonts, scripts, styles, and original illustrations are served from this site itself. The site uses system fonts and does not request a remote font service.

No ads or analytics are loaded in this version

This release includes no analytics library, advertising script, third-party embedded video, tracking pixel, or advertising cookie. The publisher’s AdSense ownership meta tag is static page metadata; it does not by itself contact an ad server or indicate approval.

Future advertising would require a fresh review of data flows, applicable disclosures, and consent requirements before activation. This policy describes the code currently included, not a promise about an unimplemented advertising system.

External reference links lead to the official Terraria Wiki, GitHub, or other explicitly named destinations. Those websites have their own privacy practices. Merely viewing this site does not load their pages; following a link does.

Your controls and questions

  • Use Reset checklist to clear active planner progress.
  • Use your browser’s site-data settings to remove storage for this website origin.
  • Export a backup before switching browsers or clearing data.
  • Close private browsing windows knowing that progress may not be retained.

The project’s publisher is available through the public GitHub profile. There is no contact form on this site and no claim that a separate support inbox is monitored.
