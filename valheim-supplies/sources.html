Method, catalog & sources / Checked 21 October 2026

A small catalog.
An open notebook.

Hearth & Pack plans equal per-player supplies using seven specific, normal Valheim recipes. It is not a complete recipe database, progression guide, food optimizer, or guarantee of compatibility with every current or future game build.

The recipe ledger.

Each link below is the community reference used to check that row. These are community-maintained sources, not an official game-data API. “Yield” is the base finished output from one full recipe; the mead rows combine making one base and fermenting it.

How the numbers are calculated.

  1. Party target = player count × per-person target.
  2. Missing finished items = the greater of zero and target − finished stock.
  3. Recipe batches = missing finished items ÷ base yield, rounded up.
  4. New output = recipe batches × base yield. Crafted extra = new output − missing finished items.
  5. For each material, add the ingredient quantities from all whole batches, then subtract that material’s stock once. Collection deficits never go below zero.

Unused finished stock is not labelled as newly crafted extra. A target of zero excludes that recipe; entering stock alone does not select it. No recipe can be selected twice, and equal packs do not allocate different roles or player names.

What is deliberately left out.

  • Cooking-skill bonus output. The planner uses guaranteed base recipe quantities rather than relying on bonus items.
  • World settings, mods, alternative recipes, and any recipe not shown above.
  • Fuel, station construction, workbench/cauldron upgrade materials, crafting time, and fermentation time.
  • Bases already made or fermenting, intermediate items, food and mead effects, eating frequency, trip duration, weight, and inventory stack slots.
  • Game-save import, multiplayer synchronization, cloud accounts, and live recipe updates.

If an in-game recipe differs from this ledger, trust your game and do not use that row as a precise requirement. The check date describes when the linked sources were read; it does not claim that the planner was tested in a particular executable game build.
