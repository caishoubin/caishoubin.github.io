Useful tools, explicit assumptions.

Each mini-site includes its own instructions, original guides, sources, and privacy information. Calculations are planning estimates, not a connection to your game save. Check each tool's supported mechanics before relying on a result.

These are independent fan projects, not affiliated with or endorsed by the games' developers. Game names belong to their respective owners. No account is required; the tools run in your browser.

Before you start

Will my work still be here next time?

The tools save valid plans or progress in this browser when browser storage is available. Private browsing or clearing site data can remove it. Use calculator share links or Terraria JSON backups to keep a copy outside the browser.

Can I move a plan to another device?

Stardew, Satisfactory, Palworld, and Valheim have copy-link controls. Open the link on the other device to load its inputs. Terraria uses exported JSON world backups instead. There is no account or automatic cloud sync.

Do these tools read my game save?

No. You enter the values and check the tasks yourself. Read each tool's assumptions and sources: these are focused planning aids, not full game simulators.
